## ⚡ Быстрый старт

### 📥 Установка

Подключитесь к роутеру по SSH и выполните команду чистой установки:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/install.sh)"

```

> После установки откройте веб-интерфейс: **LuCI → «Службы» → «SubParser»**.

### 🔄 Обновление

Обновление до актуальной версии без потери подписок, настроек и токенов:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/update.sh)"

```

### 🗑 Удаление

Полное удаление пакета, фоновых служб, записей crontab и кэша веб-интерфейса:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/uninstall.sh)"

```

## 📖 О проекте

**SubParser** — легковесный инструмент автоматизации для OpenWrt:

* Автоматическая загрузка подписок (VLESS Reality/TLS, Trojan, Hysteria2);
* Многопоточный скрининг и стресс-тестирование узлов через изолированный инстанс `sing-box`;
* Дедупликация и бесшовная выгрузка лучших серверов в профили пакета **Podkop**;
* Управление через отзывчивый веб-интерфейс LuCI и многопользовательский Telegram-бот.

---

## ✨ Ключевые возможности

### 🚀 Отбор и стресс-тестирование узлов

* **Параллельная проверка (до 12 потоков)**: экспресс-тестирование пула из сотен серверов за секунды.
* **Двухэтапная фильтрация**:
  - *Быстрый скрининг*: первичная проверка отклика через HTTP 204.
  - *Тест стабильности (Jitter Analysis)*: серия из 5 контрольных замеров для отсева серверов с потерями пакетов и нестабильной задержкой.


* **Поддерживаемые протоколы**: VLESS (Reality, TLS, WebSocket, gRPC, XHTTP), Trojan, Hysteria2.
* **Интеллектуальный фильтр RU**: автоматическое исключение российских узлов и локальных серверов обхода белых списков.
* **Лимитирование пула (Top-N)**: экспорт только Топ-3, Топ-5, Топ-10 быстрейших узлов или сохранение всех прошедших порог.
* **Защита от потери связи (Smart Fallback)**: если ни один узел не уложился в заданный пинг, выбираются наименее медленные зарубежные серверы; если пул полностью недоступен (менее 2 рабочих нод), конфигурация Podkop остаётся нетронутой с алертом администратору.
* **Контроль трафика и лимитов**: парсинг заголовков `Subscription-Userinfo` с выводом остатка трафика и срока действия подписок.
* **Обход блокировок загрузки**: автоматическая эмуляция мобильных клиентов (`Xiaomi / Android`) с генерацией уникального HWID.

---

### 📁 Интеграция с Podkop

* **Мультисекционность**: прозрачная работа с основной (`main`) и любыми пользовательскими секциями Podkop.
* **Два режима обновления**:
  - *Замена (Replace)*: перезапись списка серверов отобранным пулом.
  - *Добавление (Append)*: умное слияние с существующими серверами с дедупликацией по цифровому отпечатку (fingerprint).


* **Индивидуальная настройка**: возможность задавать персональный режим и пороги для каждого профиля отдельно.

### 🤖 Полнофункциональный Telegram-бот

Легковесный `procd`-демон с модульной архитектурой (`/usr/lib/subparser/`):

* **Многопользовательский доступ (WhiteList)**: поддержка белого списка доверенных Telegram ID (члены семьи, близкие) с управлением через веб-интерфейс LuCI.
* **Ролевая защита админ-действий**: критические операции (перезагрузка роутера, рестарт служб, пакетное удаление узлов и подписок) доступны исключительно главному администратору. Попытки несанкционированного доступа блокируются с отправкой предупреждения.
* **Аудит и логирование в реальном времени**: все входящие команды, клики по инлайн-кнопкам и попытки несанкционированного доступа логируются без задержек в системный журнал (`logread`).
* **Менеджер подписок**: добавление подписок отправкой ссылки в чат, автоопределение типа конфига, быстрое переключение User-Agent (`v2rayN`, `FlClash`, `Sing-Box`, `Happ`, `Incy`), включение/выключение и удаление.
* **Экспресс-анализ ссылок и доменов**: проверка любого URL прямо в чате (IP-резолв, задержка отклика, определение маршрута — туннель Fake-IP `198.18.x.x` или прямой канал провайдера).
* **Управление узлами и пингами**: измерение задержки при переходе в секции, ручное переключение на любой сервер, возврат в URL-Test, пакетное мультиудаление (чекбоксы + кнопка «Выбрать все [DEAD]»).
* **Контроль клиентов сети**: мониторинг подключённых Wi-Fi (2.4/5 GHz, dBm) и LAN-устройств. Мгновенная блокировка клиентов через `nftables` со сбросом активных сессий (`conntrack -D`) и очисткой кэша соседей (`ip neigh flush`).
* **Мониторинг доступности**: параллельный тест YouTube, Discord, Steam, Instagram, TikTok и сервисов РФ с индикацией типа маршрута.
* **Системные показатели**: температура процессора (SoC), аптайм, память RAM, вывод логов (`logread`, `dmesg`, лог синхронизации).
* **Интерактивный статус синхронизации**: при запуске парсера из бота статусное сообщение обновляется в реальном времени по этапам (`[1/4] Загрузка → [4/4] Запись в UCI`) без спама в чат, а по завершении меню автоматически восстанавливается.
* **Замер скорости туннеля (Speedtest)**: измерение реальной скорости скачивания через активный узел (загрузка тестового пакета 10 МБ через SOCKS-интерфейс Podkop с выводом Мбит/с).
* **Тонкая настройка порогов из чата**: возможность задать любое пользовательское значение пинга (от 30 до 3000 мс) ответным текстовым сообщением прямо в диалоге.

---

### 🌐 Веб-интерфейс LuCI

Полноценный модуль управления (**Службы → SubParser**):

* **Основные настройки**: включение службы, порог пинга, лимит серверов, фильтрация RU, кнопка ручного запуска с логом в реальном времени.
* **Секции Podkop**: индивидуальное или глобальное управление профилями и режимами добавления/замены.
* **Telegram**: настройка токена бота, основного Chat ID (Admin), динамический список доверенных пользователей (`Allowed Users`) и проверка связи.
* **Подписки**: интерактивная таблица источников с выбором User-Agent.
* **Интерактивный дашборд**: плиточный список узлов с замером задержки и ручным сохранением чекбоксами.
* **Hotplug**: автоматический перезапуск бота при сохранении изменений через триггер `etc/hotplug.d/uci/99-subparser`.

---

### ⏱ Автономность и Watchdog

* **Гибкий cron-планировщик**: периодичность раз в 1ч, 12ч, 24ч, каждые N часов или ежедневно в точное время (`ЧЧ:ММ`).
* **Умный сторожевой таймер (subparser-watchdog.sh)**: непрерывный контроль доступности REST API sing-box каждые 5 минут. Включает трехуровневую защиту от ложных тревог:
  - Проверка физической связи (WAN) через независимые DNS (Яндекс/Cloudflare);
  - Серия из 3 повторных замеров с интервалом 7 секунд для фильтрации кратковременных просадок;
  - 45-минутный кулдаун для исключения циклической нагрузки на CPU и флеш-память при затяжных сбоях.
  - При подтвержденной аварии автоматически перезапускает службу Podkop, инициирует экстренный отбор живых прокси и отправляет алерт в Telegram. 
* **Упреждающие алерты по лимитам**: watchdog ежедневно контролирует израсходованный трафик и срок действия подписок, заранее предупреждая в Telegram при остатке менее 3 дней или расходе более 90% пакета.

```text

    │   ├── screens.py                        # Генератор экранов и инлайн-клавиатур

    │   ├── system.py                         # Мониторинг ОС, nftables и клиенты сети
    │   └── telegram.py                       # Клиент Telegram Bot API
    └── usr/share/
        ├── luci/menu.d/                      # Пункт меню в LuCI
        └── rpcd/acl.d/                       # ACL-разрешения RPC для LuCI
    └── www/
        └── luci-static/resources/view/
            └── subparser.js                  # Фронтенд интерфейса LuCI

```
